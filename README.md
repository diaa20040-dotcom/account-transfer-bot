# بوت تحويل الحسابات (Telegram)

بوت تليجرام بأزرار: تحويل حساب حسب الدولة (بالنقاط)، مهام اشتراك، إحالات، وتبديل عربي/إنجليزي — مع لوحة إدارة ويب.

## المميزات

- **بدء التحويل**: اختيار الدولة → اسم الحساب → كلمة المرور → يظهر في لوحة الإدارة ويُخصم النقاط.
- **المهام**: تضيف قنوات/مجموعات من لوحة الإدارة؛ البوت يتحقق من الاشتراك إذا كان أدمنًا.
- **الإحالات**: رابط `t.me/BOT?start=ref_TELEGRAM_ID` ونقاط لكل مستخدم جديد (من الإعدادات).
- **اللغة**: عربي / English من زر في القائمة.

## التشغيل

```bash
cd account-transfer-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# عدّل .env: BOT_TOKEN، ADMIN_PASSWORD، ADMIN_TELEGRAM_IDS (رقمك في تيليجرام)
python main.py
```

لوحة الإدارة على المنفذ `8765` (محلياً بعد التحميل). كلمة الدخول من `ADMIN_PASSWORD`.

## إعداد مهمة اشتراك

1. أضف البوت **أدمن** في القناة أو المجموعة.
2. احصل على `chat_id` (مثلاً عبر @userinfobot أو `@RawDataBot`).
3. أضف المهمة من **المهام** في لوحة الإدارة مع رابط الانضمام.

## الخصوصية والمجموعات

البوت **يمكن إضافته كأدمن** في قنوات/مجموعات لتحقق مهام الاشتراك، لكنه **لا يرد ولا يعرض أزرار** في الجروبات — التفاعل للمستخدمين في الخاص فقط.

### لماذا تُصفَّر البيانات على Render؟

على الخطة المجانية السيرفر **ينام** ويُعاد تشغيله — ملف SQLite يُمسح **بدون ما تعمل أنت deploy**. الحل: أضف في Render متغير **`GITHUB_BACKUP_TOKEN`** (توكن GitHub بصلاحية كتابة على المستودع) و **`GITHUB_REPO`** = `diaa20040-dotcom/account-transfer-bot`. البوت يرفع نسخة تلقائية كلما تتغيّر النقاط، وعند إعادة التشغيل يستعيد من آخر نسخة على GitHub. من الإدارة: **☁️ رفع النسخة لـ GitHub** / **♻️ جلب من GitHub**.

## تنبيه أمني

كلمات مرور الحسابات تُخزَّن لعرضها في لوحة الإدارة كما طلبت — استخدم سيرفرًا آمنًا وغيّر `ADMIN_PASSWORD` و`SECRET_KEY`. يُفضّل إلغاء أي توكن ظهر في محادثة وإنشاء توكن جديد من BotFather.
