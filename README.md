# بوت النقاط والسحب

- **💎 نقاطي** — عرض الرصيد  
- **⭐ شحن نقاط** — 1 نجمة = 1 نقطة (أي كمية تكتبها)  
- **👥 الإحالات** — نقطة واحدة لكل إحالة (`ref_`)  
- **📦 المتاح** — سحب **0.1$** (12 نقطة) أو **0.05$** (6 نقاط) رابط دفع → الرابط + الإيميل → إشعار للإدارة  
- **🎁 برومو كود** — تفعيل أكواد من لوحة الإدارة  

**لوحة الإدارة (تيليجرام):** `/admin` أو زر **🛠 لوحة الإدارة** — إحصائيات، مستخدمون، برومو، إضافة/خصم نقاط، حظر/فك حظر، طلبات السحب.

ضع `BOT_TOKEN` و`ADMIN_TELEGRAM_IDS` أو `ADMIN_TELEGRAM_USERNAMES` على الاستضافة.
